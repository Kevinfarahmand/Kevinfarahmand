# Upwork Portfolio Entry

## Title
Retail Sales Data Analysis & Excel Dashboard

## Short description
Excel-based retail sales analysis project featuring KPI calculations, regional/category analysis, profitability metrics, monthly trend reporting, conditional formatting, and a professional dashboard.

## Full description
I built a complete retail sales analysis workbook using a synthetic dataset of 360 orders.

The workbook calculates revenue, cost, profit, and margin at transaction level, then summarizes performance by region, product category, and month using formula-driven analysis.

A dashboard presents the main KPIs, regional performance, and monthly sales trends in a clean format suitable for business reporting.

Skills demonstrated:
- Microsoft Excel
- Sales Data Analysis
- Business Reporting
- KPI Analysis
- SUMIFS / Formula-Based Analysis
- Data Visualization
- Dashboard Development
- CSV / Structured Data
- Profitability Analysis

The project uses synthetic data only and contains no confidential business information.

# Retail Sales Data Analysis Dashboard

A practical Excel portfolio project demonstrating retail sales analysis, KPI reporting, formula-driven summaries, and dashboard creation.

## Dataset

The workbook contains 360 synthetic retail orders across Japanese regions in 2026. The data is fictional and contains no confidential client information.

## Analysis included

- Revenue, cost, profit, and profit margin
- Total orders and units sold
- Regional revenue and profit comparison
- Category performance
- Monthly sales and profit trend
- Conditional formatting for profitability
- Dashboard charts and KPI summary

## Excel skills demonstrated

Excel formulas, SUMIFS, structured tables, date handling, conditional formatting, charts, dashboard design, and clean business reporting.

## Portfolio files

The downloadable project package contains:
- `retail_sales_analysis_dashboard.xlsx` — main workbook
- `retail_sales_data.csv` — synthetic source data
- `UPWORK_PORTFOLIO_TEXT.md` — ready-to-use Upwork portfolio description

# Upwork Portfolio Entry

## Title
MATLAB Signal Analysis & Anomaly Detection

## Short description
Engineering signal-analysis project built in MATLAB to demonstrate practical skills in noisy time-series processing, FFT analysis, robust anomaly detection, visualization, and structured CSV output.

## Full description
I developed a self-contained MATLAB workflow for analyzing a noisy sensor signal with transient fault-like events.

The project includes synthetic signal generation, moving-median baseline estimation, robust anomaly scoring using MAD, FFT-based frequency analysis, visualization of detected events, and export of analysis results to CSV.

This portfolio example demonstrates how I approach engineering data: first understanding the raw signal, then separating normal behavior from noise and abnormal events, and finally producing clear plots and reproducible outputs.

Skills demonstrated: MATLAB, Signal Processing, Time-Series Analysis, Anomaly Detection, FFT / Frequency Analysis, Data Visualization, Engineering Data Analysis, CSV / Table Export.

The project uses synthetic data only and does not contain any confidential client information.
